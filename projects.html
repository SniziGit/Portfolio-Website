VR Game (Solo School Project)

Bomwerks Co.

  • Solo project. Theme more absurdist in nature.
  • Game takes place where the player runs a bomb defusal service in their store and they're tasked to defuse a bomb before a timer runs out. They follow instructions provided in their office and use their tools in their store room to defuse the bombs in the right order. If done incorrectly or the timer runs out, the player loses.
  • A VR Game able to be emulated on PC using a modified version of a VR package provided by school that was using Google's VR SDK.
  • Map is created using assets from the Unity asset store then taking a 360 panoramic image of each room using a package provided by school.
  • UI was designed by me to be absolutely minimal, putting more emphasis on UX for pausing, menu screens to be limited to the worldspace for player immersion.
  • 3D Texts are created via code using a script I made that extrudes a 2D sprite into a 3D mesh.

2-Player Couch Coop FPS Extraction Shooter (Pair School Project)

Crash Handler

  • Pair Team project. Theme Sci-fi robotics.
  • Game takes place where two robots controlled by 2 players are tasked to look for power crystals within a procedurally generated robot facility and then locate a warp pad to escape.
  • A 2-Player Couch Coop FPS Extraction Shooter where the map is procedurally generated each time. So no two maps are the same.
  • Most of the 3D models except environment assets were created by me using Maya and textured with unity material balls.
  • Game uses proc-gen that I coded to be rather unorthodox and admittedly inefficient. It starts by generating a "seed" room and additional rooms will branch out from the "seed" room to create the rest of the map. Then room culling will execute to clear newer rooms that intersect with corridors and other rooms that were generated earlier in the process.
